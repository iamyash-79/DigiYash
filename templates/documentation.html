API Authentication

Secure communication between your solar CRM and our automation engines is handled via OAuth 2.0 or secure Bearer tokens.

Auth_Example.js
async function connectToSahuOne(apiKey) {
  const response = await fetch('https://api.sahuone.com/v1/auth', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${apiKey}`,
      'Content-Type': 'application/json'
    }
  });
  return response.json();
}
